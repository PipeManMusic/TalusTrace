# feature wires

## 1. OverviewThe Wire is the primary connective entity in Talus Trace. 
It represents both a logical electrical signal and a physical conductor. To support the "Draft-First" workflow, wires can exist in an incomplete state while still maintaining connectivity and topological intelligence.
### Core Traits
Draft-First Lifecycle: Wires begin in an UNDEFINED status (no gauge, material, or color) to allow for zero-friction sketching.Inferred Bundling: Wires do not belong to bundles; instead, bundles "emerge" when wires share spatial coordinates on the grid.Orthogonal Routing: Wires are rendered as polylines that snap to a 20px grid, supporting right-angle "elbows" for clean diagrams.Signal Propagation: Wires carry a signal identity that "tunnels" through transparent components like twisted pairs.2. Visual Anatomy2.1. The SegmentLine Style: Standard solid line. In UNDEFINED status, wires use the wire_default theme color (Grey).Dynamic Thickness: In Diagram Mode, thickness is fixed. In Formboard Mode, thickness is driven by the outside_diameter (OD) value from the assigned Engineering Standard.2.2. The Grips (Nodes)Terminus Grips: Located at the start and end of the wire. Snaps to Device Pins.Segment Grips: Located at the midpoint of wire segments. Dragging a segment grip creates new orthogonal elbows.3.
